# Ash Drive

An interactive car dashboard built with ashui, based on the README banner.
Each dock button opens a working page. The app plays music and follows the
system's light or dark appearance.

| Page     | What works                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| Navigate | A street map with a route to a charger, zoom keys, a search that narrows the chargers, start and end of guidance.  |
| Media    | Three tracks played by hlavi: play and pause, seek, volume, next and previous, shuffle, repeat, a visualiser. |
| Vehicle  | The 3D car with its callouts, the speed and gear, the climate dial, the paint, the doors, the energy chart.        |
| Charging | The battery ring, the charge limit, the charging curve, and the chargers nearby, each a press from guidance.       |
| Camera   | Front, rear, side and top views of the car, drag to look round, scroll to move closer, the parking sensors.        |
| Phone    | A keypad, contacts, a call that rings and runs with its clock, and the recent calls. No real call is placed.       |
| Profile  | Who is driving, which sets the climate and the paint, the appearance (Auto, Light, Dark) and the units.            |
| More     | Brightness, sounds, notifications and quiet hours, and what the app is made of.                                    |

The island across the top plays the same track as the Media page, and its play key and scrubber work from any page.

## Running it

On the desktop, from the repository root:

```sh
apps/dashboard/run.sh
```

It builds the native libraries it needs (blinc_abi, hlwgpu, hlwindow and hlavi), compiles the program and opens it on Ash. It needs
the sibling checkouts that `tools/demo/run.sh` does, and `../hlavi` as well, for the music.

In a browser, the program is built for a page as `docs/web.md` describes, with hlavi's web build beside it for the music.
`tests/wasm/run.sh Dashboard` builds it, serves it and opens it; it needs a browser with WebGPU. The browser starts the music only
after a press, so the first press of the play key is the one that starts it.

`apps/dashboard/check.sh` type-checks the program without building it, and `apps/dashboard/preview.sh` draws a page to a PNG:

```sh
TAB=Charging SCHEME=light apps/dashboard/preview.sh      # .ashui/snapshots/dashboard-Charging-light.png
```

`WIDTH` and `HEIGHT` set the size, and `CALL=1` shows the phone on a call.

## How it is made

Page data comes from signals in `Model`, `Music` and `Phone`.
`Model.step` runs the simulation: cruising, charging and route progress.
`Dashboard.page` creates pages on demand, so inactive pages are not mounted.
The 3D background draws only on the Vehicle and Camera pages.

`dashboard.css` declares the classes used by HXX. It supplies the gray page
gradient and tinted frosted cards, with scheme-specific colors selected by
`prefers-color-scheme`. Canvas drawing uses `Ink` to read current theme colors.

`WindowTheme` follows system appearance until Profile selects Light or Dark.
Selecting Auto restores system tracking.

The pages follow two HXX reactivity rules:

1. Interpolation must read a signal directly through `.get()` to track it.
   `Widgets.live` wraps functions that read signals indirectly.
2. Create conditional elements inside their `<if>` branch. Call a builder
   such as `{stopKey()}` instead of inserting an element built beforehand.

## The music

The demo includes three tracks. **Night Drive** is original, generated by
`tools/compose.py` using NumPy for synthesis and ffmpeg for encoding.
The other two recordings were released under CC0 by their creators:

| Track                                                                   | By                | Source                                                      |
| ----------------------------------------------------------------------- | ----------------- | ----------------------------------------------------------- |
| Lofi Fusion (the recording is titled "Lofi Fusion Background Music")    | Seth_Makes_Sounds | https://freesound.org/people/Seth_Makes_Sounds/sounds/655516 |
| Cosmic Dark Synthwave (titled "Cosmic dark synthwave")                  | Projecteur        | https://freesound.org/people/Projecteur/sounds/615546        |

CC0 asks for no credit, and the credit is given anyway, on the More page's About card. The files in `audio/` were made from
Freesound's 128 kbps previews; a better source file, from a Freesound account, can be run through the same script.

`tools/prepare.py <recording> <name>` trims trailing silence, normalizes to
-14 LUFS and encodes the track. It also writes `levels/<name>.bands` with
16 loudness bands sampled 30 times per second for the visualizer.
The printed duration is used in `Music.TRACKS`.
Running `tools/compose.py` again regenerates Night Drive's files.
