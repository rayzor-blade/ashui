# Control Center icons

SVG paths are copied inline into `../../ControlCenter.hx`, so the whole UI remains direct HXX markup. The demo does not fetch icons at runtime.

## Tabler Icons

Source: [tabler/tabler-icons](https://github.com/tabler/tabler-icons/tree/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d).
License: [MIT](Tabler-LICENSE.txt).

The rotation lock combines `rotate-clockwise` and `lock`. All other Tabler paths are used unchanged, with the demo supplying size and inherited color. The empty battery outline uses a thinner 1.5-unit stroke; other icons retain the source's 2-unit stroke.
