# Map data

- `kings-cross.json`: roads, rail, the Regent's Canal, parks and buildings round King's Cross, London, from [OpenStreetMap](https://www.openstreetmap.org/copyright), © OpenStreetMap contributors, available under the [Open Database Licence](https://opendatacommons.org/licenses/odbl/) (ODbL 1.0). Fetched through the Overpass API, projected to metres from 51.5355 N, 0.1240 W and simplified to within a metre; `route` is the shortest drive along its roads from `places.car` to Granary Square. The README banner's map draws it.
- `car-top.png`: a car seen from above, by Freepik - Magnific.com (attribution required), cropped and scaled down; the banner's map marks the car's place with it.
